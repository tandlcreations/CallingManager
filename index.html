TWO WAYS TO USE CALLINGMANAGER.COM

1. Load demo calling data

If you don't have access to Leader and Clerk Resources or just want to kick the tires, try the demo below.

2. Copy and paste from ChurchOfJesusChrist.org

  1. First, log into LCR as you normally would.
  2. Click this link to display LCR calling data.
  3. Copy all the text on the page ("CTRL A" to select all, then "CTRL C" to copy)
  4. Paste into the first box below ("CTRL V" to paste)
  5. While logged into LCR, visit the Member List API (link will activate after pasting calling data)
  6. Copy all the JSON text that appears and paste it into the second box below
  7. Optionally, you can include "Out of Unit Callings" by:
    1. Visiting the "Out of Unit Callings" page.
    2. Selecting all the text that appears and pasting it into the third box below.
  8. Then submit the form to continue
