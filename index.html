Quick Import (Recommended)

  1. Drag this link to your bookmarks bar: 📋 Fetch LCR Data
  2. Step 1: Open the LCR Organizations page and click the bookmarklet. A green bar will confirm "Step 1/2 done".
  3. Step 2: Navigate to the Members With Callings report and click the bookmarklet again. The green bar will say "Step 2/2Done".
  4. Come back here and click the button below.
Manual Copy & Paste (No Bookmarklet)

If you can't use the bookmarklet, you can copy the raw page source from two LCR pages instead.

  1. First, log into LCR as you normally would.
  2. Step 1 — Organizations:
    1. Open the LCR Organizations page and wait for it to fully load.
    2. Right-click anywhere on the page and choose View Page Source (or press Ctrl+U / ⌥⌘U).
    3. In the source tab that opens, Select All (Ctrl+A / ⌘A) then Copy (Ctrl+C / ⌘C).
    4. Come back here and Paste (Ctrl+V / ⌘V) into the first box below.
  3. Step 2 — Members With Callings:
    1. Open the Members With Callings report and wait for it to fully load.
    2. Right-click → View Page Source (or Ctrl+U / ⌥⌘U).
    3. Select All (Ctrl+A / ⌘A), Copy (Ctrl+C / ⌘C).
    4. Paste (Ctrl+V / ⌘V) into the second box below.
  4. Click Submit to import.

Is This Safe to Use?

Great question! Church policy is very clear that membership data should NOT be sent to third-party servers, websites, or cloud-based service providers.

Q. But aren't I submitting data to this website?

A. While it may seem like it, the answer is NO. This website loads an application in your web browser, but all the information you enter and the work you do with that data takes place on your local computer—similar to using a spreadsheet program or other desktop software. To get a bit more technical, this page uses client-side JavaScript code to accept, parse, and output everything. No communication with the server is necessary beyond the initial page load. The only exception is the optional "Report an issue" form, which sends just the text you type into it.

Q. I'm still not sure... can you prove it?

A. Of course! Not only is all the code used to manage callings open source (you can look at all the nuts and bolts yourself if you like), there is a nice and simple way to put your mind at ease:

  1. After loading this page, disconnect from wifi or unplug your internet connection
  2. Input your calling data and work offline
  3. When you are done and have printed your changes, close the browser and reconnect to the internet

About Ward Calling Manager

Why does this tool exist?

Anyone who has served in a bishopric or stake presidency knows the challenge: you need to plan, discuss, and track calling changes across multiple organizations—sometimes dozens at a time. Unfortunately, the tools available have significant limitations:

  • LCR has no scenario planning. Leader and Clerk Resources lets you make calling changes one at a time, but there is no way to draft or compare what-if scenarios before committing them.
  • Church data can’t be stored externally. Church policy prohibits sending membership data to third-party servers, cloud services, or online tools—ruling out most collaborative software.
  • Spreadsheets fall short. Tracking callings in a spreadsheet or word processor is tedious, error-prone, and hard to keep in sync with the real data in LCR.

Ward Calling Manager solves these problems by running entirely in your web browser. It imports your ward data directly from LCR, lets you create and compare multiple scenarios, and never sends a single byte of data to any server. When you’re done, you print your changes and carry them into your next meeting.

Acknowledgments

This project was inspired by callingmanager.com, which pioneered the idea of an offline calling planning tool. Ward Calling Manager builds on that concept with an updated interface, direct LCR data import, scenario comparison, and a commitment to local-only data handling.

Ward Calling Manager is an independent, open-source project and is not affiliated with, endorsed by, or connected to The Church of Jesus Christ of Latter-day Saints or callingmanager.com.
